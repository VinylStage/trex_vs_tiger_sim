Where to start

If you are new, the quickest route is to run one battle first, then look up whatever the result screen made you wonder about, in roughly this order. Each page stands on its own, so you can also jump straight to the one you need. Formulas appear only where they are needed, and every term is explained in plain words where it first appears. If you use the site for a class or a school project, please also read the limits section of the model page.

  1. Open Play and run a preset in Simple mode. Pick the species and the counts, and hundreds of runs come back as win shares with 95% confidence intervals.
  2. Read Simple mode in the guide to see how to read the bar, the interval and the still standing, fled and incapacitated counts.
  3. Compare the mass, era and group living of the species you picked in the species guide.
  4. Read the model page to learn how one run is computed and why the same setup gives a different result every run.
  5. To change the values yourself, keep the Advanced settings manual and the parameters page side by side.

What the simulator teaches

“Who would win, a T. rex or a tiger?” has no single answer. The values that fossils and field studies give come with ranges, and most behavioural values are assumptions. The simulator is built to practise putting that uncertainty into the calculation instead of hiding it.

The Monte Carlo method draws each uncertain value at random from its range, repeats the same situation hundreds or thousands of times and looks at the spread of outcomes. One run depends heavily on chance; many runs tell you how often each outcome happens.

A confidence interval shows how precisely that share is known. More runs narrow it, but no number of runs fixes an assumption that is wrong. Sensitivity analysis finds the assumptions that move the result most, which is where better data would help.

When you read a number, it helps to check three things together: not just the win share but how wide its interval is, which assumptions the result leans on, and whether those assumptions are literature values or estimates. The parameters page and the species guide tag every value with its evidence level.

You can also watch effects that only appear in numbers, such as the pack buff and a group’s morale breaking: one animal and ten animals of the same species fight very differently. Every result is a statement about the model’s rules; it does not predict or endorse real animal fights.
