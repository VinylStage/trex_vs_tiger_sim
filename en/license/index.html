Pretendard typeface

All text on the site is set in Pretendard 1.3.9 (variable, dynamic subset). The font files are served by this site itself, not by a font CDN, and are licensed under the SIL Open Font License 1.1.

  • Copyright (c) 2021, Kil Hyung-jin, with Reserved Font Name 'Pretendard'.
  • Pretendard builds on Inter (The Inter Project Authors), Source Han Sans (Adobe) and M PLUS 1 (The M+ FONTS Project Authors); their notices are part of the full text below.
  • License text and FAQ: openfontlicense.org

Everything else

The simulator and the help pages load no other libraries at run time. The engine, charts and replay are written from scratch for this project. Development tools used for the build, such as Vite and TypeScript, are not part of the deployed files.
