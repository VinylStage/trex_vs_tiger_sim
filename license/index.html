라이선스

라이선스와 오픈 소스 고지

티렉스 대 호랑이 시뮬레이터는 MIT 라이선스로 공개된 오픈 소스 프로젝트입니다. 이 페이지에는 라이선스 전문과, 사이트와 함께 배포되는 제3자 구성 요소의 고지를 모았습니다.

요약

  • 이 사이트의 소스 코드, 문서, 브랜드 이미지는 MIT 라이선스를 따릅니다. 저작권 고지와 라이선스 문구를 함께 남기면 누구나 무료로 쓰고, 복사하고, 고치고, 다시 배포할 수 있습니다.
  • 소프트웨어는 “있는 그대로” 제공되며, 어떤 보증도 하지 않습니다. 정확한 조건은 아래 전문이 기준입니다.
  • 사이트가 함께 배포하는 제3자 구성 요소는 Pretendard 글꼴 하나이며, SIL Open Font License 1.1을 따릅니다.

적용 범위

MIT 라이선스는 GitHub 저장소 VinylStage/trex_vs_tiger_sim에 있는 다음 자료에 적용됩니다.

  • 소스 코드: 시뮬레이션 엔진, 통계, 차트, 재생 화면, 웹 페이지와 빌드 설정을 포함한 모든 코드
  • 문서: 이 사이트의 안내 페이지와 저장소의 설명 문서(모델 설명, 파라미터 근거 등)
  • 브랜드 이미지: 파비콘, 앱 아이콘, 공유용 OG 이미지와 이를 만드는 스크립트

저장소에 들어 있더라도 제3자가 만든 구성 요소는 각자의 라이선스를 따릅니다. 아래 제3자 구성 요소를 참고하세요. 시뮬레이터로 직접 계산한 결과와 그 화면은 자유롭게 공유해도 됩니다.

제3자 구성 요소

Pretendard 글꼴

사이트의 모든 글자는 Pretendard 1.3.9(가변 글꼴, 동적 서브셋)로 표시합니다. 글꼴 파일은 외부 CDN이 아니라 이 사이트에서 직접 제공하며, SIL Open Font License 1.1을 따릅니다.

  • Copyright (c) 2021, Kil Hyung-jin, with Reserved Font Name 'Pretendard'.
  • Pretendard는 Inter(The Inter Project Authors), Source Han Sans(Adobe), M PLUS 1(The M+ FONTS Project Authors)을 바탕으로 만들어졌으며, 각 저작권 고지는 아래 전문에 있습니다.
  • 라이선스 원문과 자주 묻는 질문: openfontlicense.org

그 밖의 구성 요소

시뮬레이터와 안내 페이지는 실행 시점에 다른 라이브러리를 불러오지 않습니다. 엔진, 차트, 재생 화면은 모두 이 프로젝트에서 직접 작성한 코드입니다. 빌드에 쓰는 Vite, TypeScript 같은 개발 도구는 배포되는 파일에 포함되지 않습니다.

문의

라이선스에 관한 질문이나 고지 누락은 GitHub 이슈로 알려 주세요. 만든 사람과 프로젝트에 대한 안내는 소개 · 문의 페이지에 있습니다.

T. rex와 호랑이는 같은 시대에 산 적이 없고, 모든 상호작용 규칙은 가정입니다. 결과는 불확실한 입력에 따라 승패가 어떻게 달라지는지 보여 주는 교육용 모델일 뿐 실제 싸움의 예측이 아니며, 이 사이트는 실제 동물 싸움을 조장하거나 지지하지 않습니다.
